# Repository skills

The repository keeps two workflows:

- `refine-blueprint`: repeatedly use the map to discover and implement more natural mathematical
  objects, coordinates, and theorem factorizations in Lean.
- `review-blueprint`: verify the smallest complete mathematical chain affected by a change, or every
  selected node for a final PR or release audit.

The proof-map conventions live in `blueprint/README.md`; field vocabulary and evidence live in
`blueprint/terminology/`.
